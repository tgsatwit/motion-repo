# Animate in React

<p className="lead">Build fluid interfaces with declarative <code>motion</code> components. This page doubles as a template for a framework guide — every example below is live.</p>

## Install

<Tabs labels={["npm", "pnpm", "yarn", "bun"]}>
```bash
npm install motion
```
```bash
pnpm add motion
```
```bash
yarn add motion
```
```bash
bun add motion
```
</Tabs>

Then import from `motion/react`:

```tsx
import { motion } from "motion/react"
```

## Your first animation

Any HTML or SVG element has a `motion` counterpart. Give it an `animate` prop and it animates whenever those values change. Values in `initial` are used on mount.

```tsx
<motion.div
  initial={{ opacity: 0, scale: 0.5 }}
  animate={{ opacity: 1, scale: 1, rotate: 180 }}
  transition={{ duration: 0.8 }}
/>
```

### Keyframes

Pass an array to animate through a sequence of values. `times` controls where each keyframe lands.

```tsx
<motion.div
  animate={{
    scale: [1, 1.4, 1.4, 1, 1],
    rotate: [0, 0, 180, 180, 0],
  }}
  transition={{ duration: 2, repeat: Infinity }}
/>
```

## Gestures

`whileHover`, `whileTap` and `drag` add interactions with no event handlers. Try dragging the box.

```tsx
<motion.div
  drag
  dragConstraints={{ top: -60, left: -120, right: 120, bottom: 60 }}
  whileHover={{ scale: 1.1 }}
  whileTap={{ scale: 0.9 }}
/>
```

## Layout animations

Add the `layout` prop and a component animates to its new position and size whenever a re-render changes its layout — even for properties CSS can't transition, like `justify-content`.

```tsx
<button data-on={on} onClick={() => setOn(!on)}>
  <motion.span layout />
</button>
```

### Shared layout

Give two elements the same `layoutId` and Motion animates between them when one replaces the other. The sidebar, header and table of contents on this site all use this technique.

```tsx
{active === tab && <motion.span layoutId="underline" />}
```

## Exit animations

Wrap conditionally rendered elements in `AnimatePresence` to animate them out before they're removed.

```tsx
<AnimatePresence>
  {visible && (
    <motion.div
      key="box"
      initial={{ opacity: 0, scale: 0 }}
      animate={{ opacity: 1, scale: 1 }}
      exit={{ opacity: 0, scale: 0 }}
    />
  )}
</AnimatePresence>
```

## Scroll animations

`whileInView` animates an element as it enters the viewport.

```tsx
<motion.div
  initial={{ opacity: 0, y: 40 }}
  whileInView={{ opacity: 1, y: 0 }}
  viewport={{ amount: 0.6 }}
/>
```

<Example replay={false} label="Scroll-triggered" minHeight={300}>
  <InViewDemo />
</Example>

For scroll-*linked* effects, `useScroll` returns motion values you can pipe into styles. The progress bar at the top of this page is built this way:

```tsx
const { scrollYProgress } = useScroll()
const scaleX = useSpring(scrollYProgress)

return <motion.div style={{ scaleX }} />
```
