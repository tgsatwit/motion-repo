## Adding a page

<Steps>
<Step>

### Create the file

Add `app/docs/your-page/page.mdx`. The folder name becomes the URL: `/docs/your-page`.

<CodeBlock title="app/docs/your-page/page.mdx" lang="mdx" code={`import { DocPage } from "@/components/site/DocPage"

export const metadata = { title: "Your page" }

<DocPage section="Guides">

# Your page

Write markdown here.

</DocPage>`} />

</Step>
<Step>

### Add it to the navigation

Add an entry to `sharedNav` or `platformNav` in `lib/site.ts`, and to `pageOrder` if it should appear in the previous/next links.

</Step>
</Steps>

## Code

Fenced code blocks are highlighted with Shiki in light and dark themes, and get a copy button.

```ts
export function greet(name: string) {
  return `Hello, ${name}`
}
```

Use `<CodeBlock>` directly when you want a filename header:
