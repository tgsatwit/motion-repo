## Install

<Steps>
<Step>

### Add the extension

Search for **Acme Studio** in your editor's extension marketplace, or install from the command line:

<Tabs labels={["VS Code", "Cursor", "Windsurf"]}>
```bash
code --install-extension acme.studio
```
```bash
cursor --install-extension acme.studio
```
```bash
windsurf --install-extension acme.studio
```
</Tabs>

</Step>
<Step>

### Open a file with animations

Studio detects animation code automatically and adds inline previews next to transitions, easing curves and springs.

</Step>
<Step>

### Click a preview to edit

Each preview opens the matching editor below. Changes write straight back to your source.

</Step>
</Steps>

## Timeline

The timeline shows every animated value on its own track, so you can see how a sequence fits together at a glance. Press play, scrub the ruler, or drag a keyframe ◆ to retime it.

<Timeline />

<Callout type="info">
  Values are eased between keyframes and drive a real `motion.div` through motion values, so the preview runs off React's render loop.
</Callout>

## Curve editor

Drag the two handles to shape a cubic bézier easing curve. Pull a handle above the frame to overshoot.

<CurveEditor />

## Spring editor

Springs feel natural because they're driven by physics rather than a fixed duration. Adjust stiffness, damping and mass to see the response curve change live. The output includes a CSS `linear()` easing you can paste into plain stylesheets.

<SpringEditor />
