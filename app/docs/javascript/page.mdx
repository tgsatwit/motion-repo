# Animate with JavaScript

<p className="lead">The <code>animate()</code> function works with any element, in any framework — or none at all. A template for a vanilla JS guide.</p>

## Install

<Tabs labels={["npm", "CDN"]}>

## animate()

Pass an element (or a CSS selector), the values to animate to, and optional transition settings.

```js
import { animate } from "motion"

animate(".box", { x: 100, rotate: 360 }, { duration: 1.2 })
```

<Callout type="tip">

## Stagger

`stagger()` offsets each element's start time when animating a list.

```js
import { animate, stagger } from "motion"

animate(
  ".dot",
  { y: [40, 0], opacity: [0, 1] },
  { delay: stagger(0.06), type: "spring" }
)
```

## Springs

Set `type: "spring"` for physics-based motion. Springs keep their velocity when interrupted, so rapid clicks feel natural.

```js
animate(element, { x: 100 }, {
  type: "spring",
  stiffness: 300,
  damping: 12,
})
```

## Scroll

`scroll()` links an animation's progress to scroll position — of the page or any scrollable container.

```js
import { animate, scroll } from "motion"

scroll(
  animate(".progress", { scaleX: [0, 1] }),
  { container: document.querySelector(".scroller") }
)
```
